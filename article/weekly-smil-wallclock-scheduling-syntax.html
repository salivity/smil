Weekly SMIL Wallclock Scheduling Syntax

This guide explains how to schedule recurring weekly multimedia presentations in SMIL (Synchronized Multimedia Integration Language) using wallclock timing rules. It outlines the standardized syntax requirements based on ISO 8601 intervals, breaks down each element of the schedule declaration, and provides functional code examples ready for deployment in compliant media players and digital signage environments.

The Core Wallclock Syntax

SMIL uses the wallclock() timing function within the begin and end attributes of presentation elements. To define a recurring schedule, SMIL relies on ISO 8601 recurrence designators formatted as:

wallclock(R/[start_time]/[interval])
  • R: Designates a recurrence rule. Writing R without a following number indicates an indefinite repeat. To limit the schedule to a set number of weeks, append an integer (e.g., R10 for 10 occurrences).
  • start_time: The initial date and time formatted as YYYY-MM-DDTHH:MM:SS.
  • interval: The duration between occurrences, represented by P followed by the period unit. For a weekly repetition, use P1W (Period: 1 Week) or P7D (Period: 7 Days).

Implementation Example

To trigger a presentation every Monday starting on October 6, 2025, at 09:00:00 with a duration of two hours, apply the following markup to your root sequence or media container:

<smil xmlns="http://www.w3.org/ns/SMIL" version="3.0" baseProfile="Language">
  <body>
    <par 
      begin="wallclock(R/2025-10-06T09:00:00/P1W)" 
      dur="PT2H">
      <video src="presentation.mp4" />
    </par>
  </body>
</smil>

Specifying End Times with Wallclock

Instead of using the dur attribute, you can define an explicit end wallclock rule using the same recurrence pattern:

<par 
  begin="wallclock(R/2025-10-06T09:00:00/P1W)" 
  end="wallclock(R/2025-10-06T11:00:00/P1W)">
  <!-- Content runs from 09:00:00 to 11:00:00 every week -->
  <video src="presentation.mp4" />
</par>

Digital Signage Day-of-Week Extensions

Certain commercial SMIL engines (such as a-SMIL used in digital appliances) support an abbreviated day-of-week format alongside standard ISO 8601. In these profiles, days are denoted as w1 (Monday) through w7 (Sunday).

To schedule content every Monday at 09:00:00 in these environments:

<par begin="wallclock(w1T09:00:00)" dur="PT2H">
  <video src="presentation.mp4" />
</par>

For cross-platform compliance across standard SMIL 3.0 implementations, the ISO-based wallclock(R/YYYY-MM-DDTHH:MM:SS/P1W) format remains the recommended standard.
