SMIL Color Transitions Using Hex Values

This guide outlines how to create smooth color transitions using hexadecimal values in Synchronized Multimedia Integration Language (SMIL), most commonly used within Scalable Vector Graphics (SVG). By utilizing the SMIL <animate> element, you can dynamically interpolate presentation attributes such as fill, stroke, or stop-color between defined hex color codes over a set duration.

The Basic <animate> Syntax

To transition a color from one hexadecimal value to another, nest an <animate> element inside the target SVG graphical element. The basic syntax uses the attributeName, from, to, and dur (duration) attributes.

<rect width="100" height="100" fill="#FF0000">
  <animate 
    attributeName="fill" 
    from="#FF0000" 
    to="#0000FF" 
    dur="3s" 
    fill="freeze" />
</rect>

Key Attributes Defined:

  • attributeName: The target attribute to animate (e.g., fill, stroke, stop-color).
  • from: The starting color, defined in 3-digit (#RGB) or 6-digit (#RRGGBB) hexadecimal format.
  • to: The ending color, defined in hexadecimal format.
  • dur: The clock-value duration for the transition (e.g., 2s, 500ms).
  • fill="freeze": Optional. Keeps the element at the final to color once the animation finishes instead of resetting to the initial state.

Multi-Step Transitions Using the values Attribute

If a transition involves more than two colors, use the values attribute instead of from and to. Multiple hexadecimal codes are separated by semicolons.

<circle cx="50" cy="50" r="40" fill="#E63946">
  <animate 
    attributeName="fill" 
    values="#E63946; #F1FAEE; #A8DADC; #457B9D" 
    keyTimes="0; 0.33; 0.66; 1"
    dur="6s" 
    repeatCount="indefinite" />
</circle>

Controlling Timing with keyTimes:

  • values: Semicolon-delimited list of hex color codes executed in order.
  • keyTimes: Semicolon-delimited list of normalized time values between 0 and 1 defining when each color change in the sequence occurs. The number of values in keyTimes must match the number of entries in values.
  • repeatCount="indefinite": Loops the color animation continuously.

Animating SVG Gradient Stops

To animate colors within an SVG linear or radial gradient, apply the <animate> tag directly to the <stop> elements, targeting the stop-color attribute.

<linearGradient id="animatedGradient">
  <stop offset="0%" stop-color="#FF7A00">
    <animate 
      attributeName="stop-color" 
      values="#FF7A00; #FF007A; #FF7A00" 
      dur="4s" 
      repeatCount="indefinite" />
  </stop>
  <stop offset="100%" stop-color="#00E1D9">
    <animate 
      attributeName="stop-color" 
      values="#00E1D9; #007BFF; #00E1D9" 
      dur="4s" 
      repeatCount="indefinite" />
  </stop>
</linearGradient>

Hexadecimal Formatting Rules in SMIL

  1. Standard Formats: Both standard 6-character (#RRGGBB) and shorthand 3-character (#RGB) formats are supported.
  2. Alpha Channels: 8-digit hex codes with alpha channels (#RRGGBBAA) are not universally supported across all SMIL implementations. For transparency transitions, animate the opacity, fill-opacity, or stroke-opacity attribute separately.
  3. Punctuation: Do not include spaces between the semicolons and hex values in the values list, as this can cause parsing issues in strict XML environments.
