Rotate vs Translate in SVG animateTransform

This article explains the core differences between type="rotate" and type="translate" within the SMIL <animateTransform> element in SVG. It covers how each transformation type manipulates target elements, the syntax requirements for their values, and how their coordinate reference systems affect the resulting visual animation.

Core Functional Difference

The primary difference lies in the mechanical motion applied to the SVG element:

  • type="translate" applies a linear displacement across the canvas, shifting an element along the X and Y axes without altering its orientation or angle.
  • type="rotate" applies an angular displacement, spinning an element around a defined pivot point without shifting its base position in the coordinate space (unless an offset pivot is supplied).

Syntax and Parameters

Both types use attributes such as from, to, by, and values, but the parameters passed to these attributes serve fundamentally different purposes.

1. type="translate" Syntax

The translation type accepts up to two parameters representing spatial coordinates:

<animateTransform
    attributeName="transform"
    type="translate"
    from="0,0"
    to="100,50"
    dur="2s"
    repeatCount="indefinite" />
  • Format: <tx> [ty]
  • Parameters:
    • tx: The distance to move along the horizontal X-axis.
    • ty (optional): The distance to move along the vertical Y-axis. If omitted, ty defaults to 0.
  • Units: Defined in user space units (pixels by default).

2. type="rotate" Syntax

The rotation type accepts up to three parameters representing the rotation angle and the center of rotation:

<animateTransform
    attributeName="transform"
    type="rotate"
    from="0 50 50"
    to="360 50 50"
    dur="2s"
    repeatCount="indefinite" />
  • Format: <a> [cx cy]
  • Parameters:
    • a: The rotation angle expressed in degrees. Positive values rotate clockwise; negative values rotate counter-clockwise.
    • cx (optional): The X-coordinate of the center of rotation.
    • cy (optional): The Y-coordinate of the center of rotation.
  • Pivot Point Behavior: If cx and cy are omitted, the rotation defaults to the origin of the current user coordinate system (0,0), which is usually the top-left corner of the parent SVG container. To spin an object around its own center, cx and cy must explicitly match that center point.

Summary of Key Differences

Feature type="translate" type="rotate"
Motion Type Linear movement (panning) Angular movement (spinning)
Input Values x coordinate, optional y coordinate Rotation angle (degrees), optional cx, cy center coordinates
Default Behavior if Incomplete Second value (y) defaults to 0 Center values (cx, cy) default to origin (0,0)
Primary Visual Effect Relocates an element across the canvas Changes element orientation around a pivot
