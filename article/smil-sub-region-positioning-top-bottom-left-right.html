SMIL Sub-Region Positioning: Top, Bottom, Left, Right

SMIL sub-region positioning allows authors to position media dynamically within a defined layout region without creating separate layout containers for every element. By applying top, bottom, left, and right attributes directly to a media tag—such as <video>, <img>, or <text>—the media generates a localized sub-rectangle inside its assigned parent <region>. This guide explains how these four attributes dictate media placement, how coordinates are measured, and how conflicting values are resolved.

The Coordinate Space of Sub-Regions

When a media element references a layout region via the region attribute, it inherits that region's boundaries as its viewport. Applying top, bottom, left, or right directly to the media element overrides the default behavior of filling the entire region:

  • left: Specifies the horizontal distance from the left edge of the parent region to the left edge of the media sub-region.
  • right: Specifies the horizontal distance from the right edge of the parent region to the right edge of the media sub-region.
  • top: Specifies the vertical distance from the top edge of the parent region to the top edge of the media sub-region.
  • bottom: Specifies the vertical distance from the bottom edge of the parent region to the bottom edge of the media sub-region.

Supported Measurement Units

These attributes accept two primary value types:

  1. Pixel Values: Defined either as unitless integers or suffixed with px (e.g., left="20px" or left="20"). These create a fixed offset irrespective of the parent region's actual size.
  2. Percentages: Expressed with a % symbol (e.g., top="15%"). Percentages are evaluated relative to the size of the parent region. Horizontal offsets (left, right) use the parent region's width, while vertical offsets (top, bottom) use the parent region's height.

Calculating Size and Position

The sub-region dimensions depend on the relationship between these offset attributes and explicit width or height values declared on the media element.

Horizontal Positioning

  • left and right only: If both left and right are set without an explicit width, the sub-region width is automatically computed as:
    Parent Width - (left + right).
  • left and width: The sub-region begins at left and extends across width. A declared right attribute is ignored or overridden.
  • right and width: The sub-region ends at right offset from the right boundary, with its left edge calculated backward according to width.
  • Single attribute: If only left is provided (without width or right), the media uses its intrinsic width or fills the remaining space to the right border, depending on the fit attribute.

Vertical Positioning

  • top and bottom only: If both top and bottom are set without a declared height, the sub-region height is computed as:
    Parent Height - (top + bottom).
  • top and height: The sub-region begins at top and extends downward by height. An accompanying bottom attribute is ignored.
  • bottom and height: The sub-region terminates at the bottom offset, anchoring the media relative to the lower edge.

Interaction with the fit Attribute

Once top, bottom, left, and right establish the sub-region rectangle, the media element’s fit attribute determines how the visual content fills that computed space:

  • fill: The media stretches to match the sub-region bounds completely.
  • meet: The media preserves its aspect ratio, scaling until it hits the nearest edge of the sub-region.
  • slice: The media scales to cover the entire sub-region, cropping overflow.
  • hidden / scroll: The media renders at its natural size starting at the top-left of the sub-region, clipping or scrolling any overflow.

Example Usage

<smil xmlns="http://www.w3.org/ns/SMIL">
  <head>
    <layout>
      <root-layout width="1920px" height="1080px" />
      <region id="main_area" left="0" top="0" width="100%" height="100%" />
    </layout>
  </head>
  <body>
    <par>
      <!-- Media positioned with 5% margins on all sides -->
      <video src="clip.mp4" region="main_area" top="5%" bottom="5%" left="5%" right="5%" fit="meet" />

      <!-- Sub-region pinned to the bottom-right corner -->
      <img src="watermark.png" region="main_area" right="20px" bottom="20px" width="150px" height="50px" />
    </par>
  </body>
</smil>

By utilizing top, bottom, left, and right, SMIL enables responsive, relative positioning directly on media items, reducing the need for redundant region elements in the document header.
