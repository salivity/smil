Trigger Pop-up Notifications in SMIL Video Playback

Synchronized Multimedia Integration Language (SMIL) triggers pop-up notifications during video playback by coordinating spatial layout regions with temporal synchronization attributes. By defining a dedicated overlay region in the document layout and pairing it with precise time offsets, media markers, or interactive events, developers can schedule text, images, or interactive elements to display at specific moments during a media stream.

Defining the Spatial Layout

To display a notification over playing video, SMIL relies on the <layout> element within the document <head>. A primary <region> is defined for the video, and a secondary overlay <region> is defined with positioning coordinates (top, left, width, height) and a higher z-index. This layout ensures the notification renders directly on top of the video surface without interrupting its rendering flow.

<smil>
  <head>
    <layout>
      <root-layout width="1920" height="1080" />
      <region id="videoRegion" top="0" left="0" width="1920" height="1080" z-index="1" />
      <region id="popupRegion" top="80" left="1400" width="450" height="150" z-index="2" />
    </layout>
  </head>
  <body>
    ...
  </body>
</smil>

Temporal Synchronization Mechanisms

Within the <body> element, the video and the notification are grouped inside a parallel container (<par>). SMIL supports multiple mechanisms to trigger the notification:

  1. Relative Offset Timing: The notification is scheduled relative to the playback time of the video element. Using the begin attribute with a referenced element ID (for example, begin="mainVideo.begin + 15s"), the player evaluates the video’s timeline and displays the overlay at the designated timestamp.
  2. Media Markers and Cue Points: SMIL supports cue-point triggers embedded within media files. Using syntax like begin="mainVideo.marker(adBreak)", the notification executes dynamically when the media parser encounters a specific internal marker.
  3. Event-Based Triggers: Pop-ups can also be triggered via user interactions or external system events using syntax such as begin="button.click" or document-level signals.

Controlling Visibility and Dismissal

The lifespan of the notification is governed by temporal duration attributes:

  • Fixed Duration: Using the dur attribute (e.g., dur="5s") automatically hides the pop-up after a set time without stopping video playback.
  • Explicit Termination: Using the end attribute (e.g., end="mainVideo.end" or end="closeButton.click") removes the notification when a condition or interaction occurs.

Complete Implementation Example

The following snippet demonstrates an automated five-second notification that triggers thirty seconds into video playback:

<body>
  <par>
    <video id="mainVideo" src="content.mp4" region="videoRegion" />
    <text src="alert.html" region="popupRegion" 
          begin="mainVideo.begin + 30s" 
          dur="5s" />
  </par>
</body>

This declarative model enables modern digital signage platforms, interactive players, and streaming engines to inject dynamic overlays without altering the source video file.
