SMIL Grayscale Mask Transition Wipe Syntax Guide

This guide details the syntax for implementing custom transition wipe patterns using grayscale mask images in Synchronized Multimedia Integration Language (SMIL). It covers the structure of the <transition> declaration, explains how luminance gradients dictate wipe timing, and demonstrates how to bind the custom transition to target media elements.

Declaring the Custom Transition

Custom wipe patterns using grayscale images are declared within the <head> section of a SMIL document using the <transition> element. The grayscale image acts as a luminance map that guides the sequence of the wipe across the display area.

Syntax Structure

<head>
  <transition id="customWipeId"
              type="custom"
              src="path/to/mask.png"
              dur="2s"
              startProgress="0.0"
              endProgress="1.0"
              direction="forward" />
</head>

Key Attributes

  • id: A unique XML identifier used to reference the transition within media elements.
  • type: Specified as custom (or in certain player profiles, miscTransition or extended vendor types) to indicate an external map is being utilized rather than a predefined SMPTE wipe.
  • src: The URI path pointing to the grayscale image file (typically PNG or JPEG).
  • dur: The duration of the transition from start to finish (e.g., 2s or 1500ms).
  • startProgress (optional): The progress value at which the transition begins, ranging from 0.0 (start of mask) to 1.0. Default is 0.0.
  • endProgress (optional): The progress value at which the transition ends. Default is 1.0.
  • direction (optional): Determines whether the wipe moves forward (revealing along the gradient) or reverse.

How the Grayscale Mask Works

The rendering engine evaluates the luminance (brightness) of each pixel in the mask image:

  • Black (Value 0): Transitions immediately at the beginning of the timeline (0% progress).
  • Mid-tone Grays (Values 1–254): Transition proportionally over the course of the duration according to their brightness.
  • White (Value 255): Transitions last, concluding at the end of the duration (100% progress).

Gradients with soft edges produce a feathered or blurred wipe border, while high-contrast posterized masks create sharp, defined wipe edges.

Applying the Transition to Media Elements

To invoke the defined transition, assign its id to the transIn (entry transition) or transOut (exit transition) attribute of any SMIL media element, such as <img>, <video>, or <ref>.

Complete SMIL Document Example

<smil xmlns="http://www.w3.org/ns/SMIL" version="3.0" baseProfile="Language">
  <head>
    <layout>
      <root-layout width="1920" height="1080" backgroundColor="black" />
      <region id="mainRegion" width="1920" height="1080" />
    </layout>
    <transition id="gradientWipe"
                type="custom"
                src="transitions/radial_gradient.png"
                dur="1.5s" />
  </head>
  <body>
    <seq>
      <!-- Media transitioning in using the grayscale mask -->
      <img src="slide1.jpg" 
           region="mainRegion" 
           dur="5s" />
      <img src="slide2.jpg" 
           region="mainRegion" 
           dur="5s" 
           transIn="gradientWipe" />
    </seq>
  </body>
</smil>
