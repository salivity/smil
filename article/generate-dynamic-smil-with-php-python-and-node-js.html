Generate Dynamic SMIL with PHP, Python, and Node.js

Synchronized Multimedia Integration Language (SMIL) is an XML-based standard used to choreograph multimedia elements such as video, audio, text, and images over a timeline. This guide provides a practical overview of how to generate dynamic SMIL documents on a web server using PHP, Python, and Node.js. By dynamically serving SMIL files, streaming platforms and multimedia applications can alter video playlists, insert dynamic advertising, or adjust adaptive bitrate profiles on the fly based on database records or client requests.

Key Requirements for Dynamic SMIL Delivery

Regardless of the backend technology used, dynamically generated SMIL requires two fundamentals:

  1. The Correct MIME Type: The server must send the response with the Content-Type header set to application/smil+xml (or application/smil).
  2. Valid XML Syntax: The output must be valid XML with root <smil> tags, typically containing <head> and <body> tags enclosing sequence (<seq>) or parallel (<par>) elements.

1. Generating SMIL with PHP

PHP can generate SMIL files by setting the response header and outputting XML either via standard templates or using the DOMDocument class for strict validation.

<?php
header('Content-Type: application/smil+xml; charset=UTF-8');

// Sample dynamic media items from a database or array
$mediaItems = [
    ['src' => 'intro.mp4', 'duration' => '5s'],
    ['src' => 'main_feature.mp4', 'duration' => '120s']
];

echo '<?xml version="1.0" encoding="UTF-8"?>' . "\n";
?>
<smil xmlns="http://www.w3.org/ns/SMIL" version="3.0" baseProfile="Language">
  <head>
    <meta name="title" content="Dynamic Playlist" />
  </head>
  <body>
    <seq>
      <?php foreach ($mediaItems as $item): ?>
        <video src="<?= htmlspecialchars($item['src'], ENT_QUOTES, 'UTF-8') ?>" dur="<?= htmlspecialchars($item['duration'], ENT_QUOTES, 'UTF-8') ?>" />
      <?php endforeach; ?>
    </seq>
  </body>
</smil>

2. Generating SMIL with Python

Using a framework like Flask, you can generate SMIL dynamically using Python's built-in xml.etree.ElementTree or template engines like Jinja2. The ElementTree approach ensures the XML is properly escaped and structured.

from flask import Flask, Response
import xml.etree.ElementTree as ET

app = Flask(__name__)

@app.route('/playlist.smil')
def generate_smil():
    smil = ET.Element('smil', xmlns="http://www.w3.org/ns/SMIL", version="3.0")
    
    head = ET.SubElement(smil, 'head')
    ET.SubElement(head, 'meta', name="title", content="Dynamic Stream")
    
    body = ET.SubElement(smil, 'body')
    seq = ET.SubElement(body, 'seq')
    
    media_files = [
        {"src": "video1.mp4", "dur": "10s"},
        {"src": "video2.mp4", "dur": "15s"}
    ]
    
    for media in media_files:
        ET.SubElement(seq, 'video', src=media['src'], dur=media['dur'])
    
    xml_data = ET.tostring(smil, encoding='utf-8', xml_declaration=True)
    return Response(xml_data, mimetype='application/smil+xml')

if __name__ == '__main__':
    app.run(port=5000)

3. Generating SMIL with Node.js

In Node.js, you can build SMIL payloads using a framework like Express alongside an XML-building library such as xmlbuilder2 to prevent XML injection errors.

const express = require('express');
const { create } = require('xmlbuilder2');

const app = express();

app.get('/playlist.smil', (req, res) => {
  const mediaList = [
    { src: 'stream1.mp4', systemBitrate: '1000000' },
    { src: 'stream2.mp4', systemBitrate: '2500000' }
  ];

  const root = create({ version: '1.0', encoding: 'UTF-8' })
    .ele('smil', { xmlns: 'http://www.w3.org/ns/SMIL', version: '3.0' })
      .ele('head')
      .up()
      .ele('body')
        .ele('switch');

  mediaList.forEach(item => {
    root.ele('video', {
      src: item.src,
      'system-bitrate': item.systemBitrate
    }).up();
  });

  const xml = root.end({ prettyPrint: true });

  res.set('Content-Type', 'application/smil+xml');
  res.send(xml);
});

app.listen(3000, () => {
  console.log('Server running on port 3000');
});

Best Practices

  • Sanitize Input: Always encode user-provided variables or filenames using proper XML escaping functions to avoid generating malformed markup.
  • Caching: Set appropriate Cache-Control headers. If playlists update rarely, cache the dynamic output; if SMIL is used for real-time live ad insertion, mark responses with no-cache.
  • Validation: Test output using standard XML validators or dedicated media server parsers (such as Wowza or Nimble Streamer) to ensure compliance with SMIL schema versions.
