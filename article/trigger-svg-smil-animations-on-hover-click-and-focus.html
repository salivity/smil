Trigger SVG SMIL Animations on Hover, Click, and Focus

Synchronized Multimedia Integration Language (SMIL) allows developers to build complex, declarative animations directly within SVG code without external JavaScript or CSS. By utilizing event-value specifications inside the begin and end attributes of SMIL elements such as <animate> or <animateTransform>, animations can respond dynamically to interactive user inputs. This guide explains how to configure SVG SMIL animations to trigger on mouse hovers, clicks, and keyboard focus events.

The Core Concept: The begin and end Attributes

SMIL animation elements like <animate>, <animateTransform>, and <set> rely on the begin attribute to determine when an animation starts and the end attribute to determine when it stops. Instead of time-based values (such as begin="0s"), you can pass interactive event conditions using the syntax [element-id.]event. If no element ID is specified, the event defaults to the parent element containing the animation tag.

Triggering on Hover (mouseover and mouseout)

To trigger an animation when a user points their cursor over an SVG shape, map the begin attribute to mouseover (or mouseenter) and the end attribute to mouseout (or mouseleave).

<svg width="200" height="200" viewBox="0 0 100 100">
  <circle cx="50" cy="50" r="30" fill="#3498db">
    <!-- Expands on hover and resets on mouse leave -->
    <animate 
      attributeName="r" 
      to="45" 
      dur="0.3s" 
      begin="mouseover" 
      end="mouseout" 
      fill="freeze" />
  </circle>
</svg>

Setting fill="freeze" retains the final state while the mouse is over the element, while end="mouseout" ensures the shape reverts once the cursor leaves.

Triggering on Click (click)

Animations can also start when a user clicks on an element. The click event is declared directly inside the begin attribute.

<svg width="200" height="200" viewBox="0 0 100 100">
  <rect x="25" y="25" width="50" height="50" fill="#e74c3c">
    <!-- Rotates 90 degrees upon being clicked -->
    <animateTransform 
      attributeName="transform" 
      type="rotate" 
      from="0 50 50" 
      to="90 50 50" 
      dur="0.4s" 
      begin="click" 
      fill="freeze" />
  </rect>
</svg>

You can also create toggle-like behaviors or chain events by setting multiple triggers separated by semicolons (e.g., begin="click; otherElement.click").

Triggering on Focus (focusin and focusout)

To ensure keyboard accessibility, animations can be linked to focus events. In standard SVG, graphical elements are not focusable by default. To make an SVG element accept focus, add tabindex="0". Then, use focusin and focusout (or focus and blur) to control the animation.

<svg width="200" height="200" viewBox="0 0 100 100">
  <circle cx="50" cy="50" r="30" fill="#2ecc71" tabindex="0">
    <!-- Pulsates when the element receives keyboard focus -->
    <animate 
      attributeName="opacity" 
      values="1;0.4;1" 
      dur="1s" 
      repeatCount="indefinite" 
      begin="focusin" 
      end="focusout" />
  </circle>
</svg>

Targeting External Elements

An animation does not have to be triggered by its parent shape. By referencing the id of another SVG element, you can create interactive controls such as buttons that trigger animations elsewhere in the document.

<svg width="300" height="200" viewBox="0 0 300 200">
  <!-- Target shape -->
  <circle cx="200" cy="100" r="25" fill="#9b59b6">
    <animate 
      attributeName="cy" 
      to="40" 
      dur="0.5s" 
      begin="triggerBtn.click" 
      end="triggerBtn.mouseout" 
      fill="freeze" />
  </circle>

  <!-- Button that controls the circle -->
  <rect id="triggerBtn" x="20" y="80" width="80" height="40" rx="5" fill="#34495e" cursor="pointer" />
  <text x="60" y="105" fill="#ffffff" font-size="12" text-anchor="middle" pointer-events="none">Click Me</text>
</svg>

Using triggerBtn.click directs the SMIL engine to observe the element with the matching ID, allowing for clean, decoupled UI logic natively within SVG.
