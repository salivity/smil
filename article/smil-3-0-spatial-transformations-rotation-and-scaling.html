SMIL 3.0 Spatial Transformations: Rotation and Scaling

SMIL 3.0 (Synchronized Multimedia Integration Language) handles spatial transformations by combining declarative layout rules, dedicated multimedia modules, and timed animation elements. While SMIL is primarily an orchestration language rather than a full 2D rendering engine, it manages spatial scaling through the Layout and PanZoom modules, and processes continuous transformations like rotation and dynamic scaling via the SMIL Animation module.

Scaling and Aspect Ratio Control

Static and bounded scaling in SMIL 3.0 is primarily managed through region definitions and content-fitting rules in the Layout modules:

  • The fit Attribute: Applied to media elements or regions, the fit attribute determines how visual media scales to match target dimensions:
    • fill: Scales the media non-uniformly to completely fill the target area, ignoring the original aspect ratio.
    • meet: Uniformly scales the media until it reaches the bounds of the region, preserving the aspect ratio without clipping.
    • slice: Uniformly scales the media to completely cover the region, preserving the aspect ratio and clipping any overflowing parts.
    • hidden or scroll: Renders the media at native size, either hiding or providing scrollbars for overflowing areas.
  • Hierarchical and Sub-Region Layout: SMIL 3.0 permits nested regions using percentages and relative units, enabling automatic scaling when parent layouts resize.

The SMIL 3.0 PanZoom Module

SMIL 3.0 introduced the PanZoom module specifically for high-resolution graphics and video. It allows authoring tools and players to scale and pan into a specific bounding box of an asset over time without distorting the outer layout:

  • The panZoom attribute establishes a virtual viewing window over the target media.
  • By adjusting coordinates dynamically or over predefined durations, authors achieve zoom-in (scaling up details) and zoom-out operations directly on media surfaces.

Dynamic Transformations via <animateTransform>

For arbitrary scaling and rotation, SMIL 3.0 relies on the SMIL Animation module, often applied in host languages such as SVG:

  • Rotation: SMIL does not feature a static <region rotate="..."> attribute in its core layout syntax. Instead, rotation is handled via the <animateTransform> element with the attribute type="rotate".
    • Syntax: Values are written as <angle> [, <cx>, <cy>], where angle defines the rotation in degrees, and optional cx and cy parameters define the center coordinates around which the object rotates.
    • Application: Authors can define static rotations by setting from and to to the same angle, or animate rotations by defining differing angle values over a specified dur (duration).
  • Scaling: In addition to the fit attribute, <animateTransform> supports type="scale".
    • Syntax: Values are represented as <sx> [, <sy>], allowing both uniform scaling (a single multiplier) and non-uniform scaling (separate horizontal and vertical multipliers).

Additive and Sequential Operations

When both rotation and scaling are required, SMIL 3.0 manages them using transformation composition attributes:

  • additive="sum": Allows multiple <animateTransform> operations (such as a concurrent scale and rotate) to combine instead of overriding one another.
  • accumulate="sum": Allows repeated transformations (e.g., repeating a 45-degree rotation) to build upon the ending state of previous cycles.
