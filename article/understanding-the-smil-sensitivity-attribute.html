Understanding the SMIL Sensitivity Attribute

The sensitivity attribute in Synchronized Multimedia Integration Language (SMIL) dictates how interactive media objects respond to user input events, such as mouse clicks or pointer touches. This article explains the primary function of the sensitivity attribute, how it manages event pass-through across overlapping visual layers, and its practical application in multimedia authoring.

In SMIL, interactive presentations often feature overlapping visual media elements, such as transparent graphics, subtitles, or video overlays placed within the same display region. When a user clicks on an area where multiple media elements overlap, the rendering engine needs to determine which element captures the interaction. The sensitivity attribute directly controls this behavior by defining the threshold at which a media object responds to user-initiated pointer events.

The primary role of sensitivity involves handling transparency and event delegation:

  • Event Capture: When an interactive media object has high sensitivity, any user interaction over its active area is captured by that element, triggering associated timing events, hyperlinks, or scripts.
  • Event Pass-Through: If the media object contains transparent or semi-transparent areas (such as an alpha channel in an image or video), the sensitivity attribute determines whether interactions in those transparent zones are consumed or passed through to underlying media elements.

The attribute typically accepts a percentage value or predefined keywords depending on the SMIL profile:

  • Percentage Values (e.g., 0% to 100%): This defines the opacity threshold required to trigger an event. For instance, setting sensitivity="50%" means that pixels with an alpha opacity of 50% or higher will register pointer events, while pixels below 50% opacity will let the interaction pass through to whatever element lies underneath.
  • Full Transparency vs. Full Opacity: Setting sensitivity to 0% makes the entire bounding box of the media object responsive, regardless of transparency. Conversely, setting it to 100% ensures that only completely opaque pixels capture user clicks.

Authors use the sensitivity attribute to create complex, non-rectangular interactive regions. For example, in an interactive video with a irregularly shaped overlay graphic, configuring the sensitivity attribute prevents completely transparent areas of the overlay from blocking user interactions intended for the video playback controls beneath it. This ensures that user interactions remain precise and intuitive across layered multimedia layouts.
