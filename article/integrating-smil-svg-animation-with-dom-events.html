Integrating SMIL SVG Animation with DOM Events

Synchronized Multimedia Integration Language (SMIL) enables declarative animations directly inside Scalable Vector Graphics (SVG). This article explains how SMIL integrates with standard DOM event listeners, detailing how declarative SVG attributes capture user interactions, how JavaScript invokes SMIL animation methods, and how SMIL-specific lifecycle events can be monitored using standard DOM event interfaces.

Declarative Event Triggers in SMIL Attributes

SMIL elements—such as <animate>, <animateTransform>, and <set>—can listen directly to DOM events without external JavaScript. This is achieved using the begin and end attributes.

By default, an event specified in the begin attribute listens to the parent element of the animation:

<rect width="100" height="100" fill="blue">
  <animate attributeName="opacity" to="0.2" begin="mouseover" end="mouseout" dur="0.5s" />
</rect>

You can also target specific elements across the SVG document by prepending the element's id followed by a dot:

<circle id="triggerBtn" cx="50" cy="50" r="20" fill="red" />
<rect x="100" y="50" width="50" height="50" fill="green">
  <animate attributeName="x" to="200" begin="triggerBtn.click" dur="1s" fill="freeze" />
</rect>

Supported declarative triggers include standard UI events such as click, focusin, focusout, activate, mouseover, and mouseout.

Programmatic Control via JavaScript

When declarative bindings are insufficient, standard JavaScript DOM event listeners can control SMIL animations programmatically. SMIL elements implement the SVGAnimationElement interface, which exposes methods to control the animation timeline:

  • beginElement(): Starts the animation immediately.
  • beginElementAt(offset): Starts the animation after a defined offset in seconds.
  • endElement(): Stops the animation immediately.
  • endElementAt(offset): Stops the animation after a defined offset in seconds.

These methods can be invoked inside standard DOM event handlers attached to any HTML or SVG element:

const trigger = document.querySelector('#externalButton');
const animation = document.querySelector('#myAnimation');

trigger.addEventListener('click', () => {
  animation.beginElement();
});

Capturing SMIL Lifecycle Events

SMIL animations dispatch standard DOM events corresponding to their execution state. Standard DOM listeners can register for these events using addEventListener() to synchronize external logic, audio, or other animations:

  • beginEvent: Dispatched when the animation starts playing.
  • endEvent: Dispatched when the animation completes its duration or is stopped.
  • repeatEvent: Dispatched when the animation completes an iteration and repeats.
const animElement = document.querySelector('#myAnimation');

animElement.addEventListener('beginEvent', (e) => {
  console.log('SMIL animation started at:', e.timeStamp);
});

animElement.addEventListener('repeatEvent', (e) => {
  console.log('SMIL animation repeated.');
});

animElement.addEventListener('endEvent', (e) => {
  console.log('SMIL animation finished.');
});

Event Propagation and Scoping

Events used to trigger SMIL animations respect standard DOM event dispatching and bubbling rules. When a user clicks a nested graphic inside an SVG group (<g>), the click event bubbles up through the DOM tree. A SMIL animation attached to an ancestor element can capture this bubbling event to trigger its timeline.

However, cross-document scoping applies: SMIL declarative triggers (e.g., begin="elementId.click") can only resolve IDs located within the same SVG document fragment. To trigger an embedded SVG's SMIL animation from an external HTML button, the JavaScript DOM API and beginElement() must be used.
