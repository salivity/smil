SVG animateMotion Guide: Move Objects Along Paths

The <animateMotion> element in Synchronized Multimedia Integration Language (SMIL) enables SVG elements to move along defined vector paths dynamically. By utilizing this declarative animation element, developers can guide shapes, text, or groups along straight, curved, or complex bezier trajectories without needing external JavaScript libraries or manual frame-by-frame coordinate calculations.

The Core Purpose of <animateMotion>

In standard SVG animations, translating an object across coordinates typically involves changing the x, y, cx, cy, or transform attributes. However, these basic coordinate updates are limited to linear interpolations.

The primary purpose of <animateMotion> is to bind an element's position directly to the geometry of an SVG <path>. The browser parses the path data, determines the curve segments, and calculates the intermediate coordinates needed to transition the target object smoothly along that path over a specified duration.

Key Attributes and Mechanisms

<animateMotion> provides specialized attributes designed specifically for trajectory-based movement:

Defining the Path: path vs. <mpath>

You can specify the movement trajectory in two ways:

  • The path attribute: Embeds path commands directly within the <animateMotion> tag (e.g., path="M 0 0 L 100 100").
  • The <mpath> child element: References an external or existing <path> element defined elsewhere in the <defs> or canvas using an href attribute (e.g., <mpath href="#trajectory"/>). This allows the visual path line to be reused for the motion itself.

Automatic Orientation: rotate

A standout capability of <animateMotion> is tangential alignment:

  • rotate="auto": Automatically rotates the moving element so its horizontal axis matches the tangent angle of the vector path at every point.
  • rotate="auto-reverse": Rotates the target element 180 degrees opposite the tangent direction, useful for reversing an object's heading.
  • rotate="[degrees]": Keeps the object at a fixed angle throughout the animation.

Timing and Control Attributes

  • dur: Defines the duration of one complete traversal along the path.
  • repeatCount: Controls whether the animation runs once, multiple times, or continuously (indefinite).
  • fill: Determines whether the object returns to its starting point (remove) or remains at the end of the path (freeze).
  • keyPoints and keyTimes: Provide fine-grained control over the speed and pacing of the object at specific intervals along the path.

Basic Syntax Example

Below is a minimal implementation showing a circle following a cubic bezier curve:

<svg viewBox="0 0 500 300" width="100%" height="300">
  <!-- The visible trajectory -->
  <path id="motionPath" d="M 50 150 C 150 50, 350 250, 450 150" fill="none" stroke="#ccc" stroke-dasharray="5,5"/>

  <!-- The moving object -->
  <circle r="10" fill="#007acc">
    <animateMotion dur="4s" repeatCount="indefinite" rotate="auto">
      <mpath href="#motionPath"/>
    </animateMotion>
  </circle>
</svg>

Advantages Over Script-Based Motion

  • Performance: Handled natively by the browser's rendering engine, reducing thread overhead compared to JavaScript interval loops.
  • Simplicity: Eliminates the need to compute complex mathematical formulas (such as cubic bezier equations) to find points on a curve.
  • Portability: The entire animation lives directly within the SVG markup, making it self-contained and easily embeddable across web platforms.
