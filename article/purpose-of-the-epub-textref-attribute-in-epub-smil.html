Purpose of the epub:textref Attribute in EPUB SMIL

This article provides an overview of the epub:textref attribute used within EPUB 3 Media Overlays. It explores the technical purpose of the attribute, how it bridges the gap between Synchronized Multimedia Integration Language (SMIL) elements and XHTML markup, and its role in delivering synchronized audio playback and visual highlighting in modern e-books.

The primary purpose of the epub:textref attribute is to link synchronization data in a SMIL file to a specific element within an XHTML content document. In EPUB 3 Media Overlays, books pair pre-recorded narration with visual text. While SMIL handles the timing and audio cues, it does not display content directly; instead, it references the existing XHTML pages. The epub:textref attribute supplies the precise URI and fragment identifier (element ID) required to locate the corresponding visual text.

Establishing the Link Between Audio and Text

Within a SMIL document, narration is broken down into discrete segments, typically wrapped in parallel <par> elements. Each segment references both an audio clip and the corresponding text. The epub:textref attribute designates which part of the XHTML structure aligns with that specific audio timeframe:

  • Active Highlighting: As an audio clip defined by a <par> element plays, the EPUB reading system uses the epub:textref target to apply styling—typically visual highlighting—to that exact word, sentence, or paragraph in the XHTML file.
  • Granular Addressing: By appending an ID (such as chapter1.xhtml#sentence-2), the attribute targets granular document nodes rather than just the whole document, allowing sentence-by-sentence or word-by-word synchronization.

Enabling Bidirectional Interactivity

The connection established by epub:textref works in both directions:

  1. Audio to Text: When continuous narration plays, the reading system follows the epub:textref targets to turn pages automatically and keep the user's viewport centered on the currently spoken text.
  2. Text to Audio: When a reader taps or clicks on a specific paragraph or sentence in the XHTML document, the reading system checks the Media Overlay associations to find the matching SMIL node, allowing playback to begin immediately from that exact point in the audio track.

By mapping temporal media to the structural markup of an e-book, the epub:textref attribute ensures synchronized, accessible, and interactive reading experiences.
