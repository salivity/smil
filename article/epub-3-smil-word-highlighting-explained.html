EPUB 3 SMIL Word Highlighting Explained

EPUB 3 delivers synchronized audio and text experiences—known as Media Overlays—by using a subset of SMIL (Synchronized Multimedia Integration Language). This article explains how SMIL files map precise audio timestamps to individual HTML elements, allowing compatible e-readers to play human narration while dynamically highlighting text word by word in real time.

1. Granular HTML Markup

Word-by-word synchronization requires the underlying XHTML content to be broken down into individual elements. Because SMIL references elements using Document Object Model (DOM) fragment identifiers, every single word that needs highlighting must be enclosed in its own tag—most commonly a <span> element—with a unique id attribute.

<p>
  <span id="w1">Synchronized</span>
  <span id="w2">reading</span>
  <span id="w3">experiences.</span>
</p>

2. The SMIL File Structure

A SMIL file acts as the coordinator between the visual document (XHTML) and the auditory media (typically an MP3 or AAC file). The document relies on <par> (parallel) elements within a <seq> (sequence) container to indicate that an audio clip and a text element should be presented at the same time.

For word-by-word highlights, each <par> element pairs one word's HTML ID with a specific segment of the audio track using clipBegin and clipEnd time offsets:

<smil xmlns="http://www.w3.org/ns/SMIL" version="3.0">
  <body>
    <seq id="text_sequence">
      <par id="p1">
        <text src="chapter1.xhtml#w1"/>
        <audio src="audio/chapter1.mp3" clipBegin="00:00:00.000" clipEnd="00:00:00.650"/>
      </par>
      <par id="p2">
        <text src="chapter1.xhtml#w2"/>
        <audio src="audio/chapter1.mp3" clipBegin="00:00:00.650" clipEnd="00:00:01.100"/>
      </par>
      <par id="p3">
        <text src="chapter1.xhtml#w3"/>
        <audio src="audio/chapter1.mp3" clipBegin="00:00:01.100" clipEnd="00:00:01.900"/>
      </par>
    </seq>
  </body>
</smil>

3. Package Manifest Association

The EPUB package file (content.opf) connects the XHTML document to its corresponding SMIL file. In the <manifest>, the SMIL file is declared with the media-type application/smil+xml. The XHTML file entry then links to it using the media-overlay attribute:

<item id="chapter1" href="chapter1.xhtml" media-type="application/xhtml+xml" media-overlay="chapter1_overlay"/>
<item id="chapter1_overlay" href="chapter1.smil" media-type="application/smil+xml"/>
<item id="audio1" href="audio/chapter1.mp3" media-type="audio/mpeg"/>

4. Playback and CSS Highlighting

When an EPUB 3 reader plays the audio, it monitors the current playback time against the clipBegin and clipEnd attributes in the SMIL file. As playback crosses into a new time boundary, the reading engine does the following:

  1. Locates the active text fragment identifier specified in the <text> element.
  2. Applies a predefined CSS class (traditionally -epub-media-overlay-active) to the corresponding HTML element.
  3. Automatically removes the class when the playback duration reaches clipEnd.

Authors customize the highlight appearance via standard CSS rules within the book's stylesheet:

.-epub-media-overlay-active {
  background-color: #ffeb3b;
  color: #000000;
}

Through this continuous loop of timestamp tracking, DOM node selection, and dynamic CSS application, EPUB 3 and SMIL produce seamless, real-time word-by-word reading highlights.
