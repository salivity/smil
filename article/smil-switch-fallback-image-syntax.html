SMIL Switch Fallback Image Syntax

This guide explains how to define fallback content using the Synchronized Multimedia Integration Language (SMIL) <switch> element. By leveraging the sequential evaluation model of the <switch> container, you can ensure that an alternative image or text message displays reliably if a primary image file cannot be rendered or fails evaluation tests.

In SMIL, the <switch> element allows authors to present alternative media elements. The SMIL player evaluates the child elements inside the <switch> block in the exact order they appear, selecting the first element whose test attributes evaluate to true and whose media format is supported. To define a fallback, you place the primary element first and the default or fallback element last, typically omitting test attributes on the final element so it serves as an unconditional catch-all.

Standard Fallback Syntax

<smil xmlns="http://www.w3.org/ns/SMIL" version="3.0" baseProfile="Language">
  <body>
    <switch>
      <!-- Primary Image Element with a condition -->
      <img src="primary-graphic.png" 
           systemRequired="image/png" 
           alt="High-resolution primary image" />

      <!-- Secondary Fallback Image -->
      <img src="fallback-graphic.jpg" 
           systemRequired="image/jpeg" 
           alt="Standard fallback image" />

      <!-- Default Catch-All Fallback (Text/Audio) -->
      <text src="data:text/plain,Image%20unavailable" />
    </switch>
  </body>
</smil>

Key Elements of the Fallback Mechanism

  1. Sequential Evaluation: The SMIL player checks child elements from top to bottom. Once an element evaluates successfully and can be rendered, the remaining alternatives inside that <switch> element are completely ignored.
  2. Conditional Test Attributes: Attributes such as systemRequired, systemBitrate, systemScreenSize, or systemLanguage establish the criteria for the primary elements. If the target environment fails to meet these criteria, the player proceeds to the next candidate.
  3. The Unconditional Fallback: The last element within the <switch> tag should omit conditional system* attributes. This ensures that if all preceding choices fail, the player defaults to this final option rather than displaying a broken media link or nothing at all.
