Visualizing Radar Sweeps Using SMIL Animation

Synchronized Multimedia Integration Language (SMIL) allows developers to build smooth, timed vector animations directly inside Scalable Vector Graphics (SVG) without relying on heavy external JavaScript libraries. This article explains how to translate radar sweep data into visually timed animations using SMIL, covering how to rotate a continuous sweep line, synchronize detected target blips based on angular timing, and simulate realistic phosphor-decay fading effects through declarative SVG attributes.

1. Setting Up the Radar Grid Base

A radar interface consists of concentric range rings, azimuth angle lines, and a central pivot. In SVG, these are defined using basic <circle> and <line> elements inside a coordinate viewBox.

<svg viewBox="0 0 400 400" width="100%" height="100%" xmlns="http://www.w3.org/2000/svg">
  <!-- Radar Background and Rings -->
  <rect width="400" height="400" fill="#051005" />
  <circle cx="200" cy="200" r="150" fill="none" stroke="#1a551a" stroke-width="1" />
  <circle cx="200" cy="200" r="100" fill="none" stroke="#1a551a" stroke-width="1" />
  <circle cx="200" cy="200" r="50" fill="none" stroke="#1a551a" stroke-width="1" />
  <line x1="200" y1="50" x2="200" y2="350" stroke="#1a551a" stroke-width="1" />
  <line x1="50" y1="200" x2="350" y2="200" stroke="#1a551a" stroke-width="1" />
</svg>

2. Animating the Continuous Sweep Beam

The core of a radar display is the rotating beam. In SMIL, continuous circular motion is achieved using the <animateTransform> element applied to a sweep line or a transparent gradient wedge that represents the scanner's field.

<!-- Rotating Sweep Line -->
<line id="sweepLine" x1="200" y1="200" x2="200" y2="50" stroke="#00ff66" stroke-width="2">
  <animateTransform 
    id="radarSweep"
    attributeName="transform" 
    type="rotate" 
    from="0 200 200" 
    to="360 200 200" 
    dur="4s" 
    repeatCount="indefinite" />
</line>
  • dur="4s": Establishes the scan period. The sweep takes precisely four seconds to complete a 360-degree rotation.
  • from/to: Dictates rotation around the radar center (200, 200).

3. Synchronizing Detected Targets with Sweep Timing

Radar sweep data typically arrives as polar coordinates: an azimuth angle (\(\theta\)) and a distance (\(r\)). To accurately reflect real-world radar sweeps, a target blip must illuminate at the exact moment the sweep beam crosses its coordinates.

Because the total sweep duration (\(T\)) covers \(360^\circ\), the activation delay (\(t\)) for any target at azimuth \(\theta\) (measured clockwise from \(0^\circ\)) is calculated as:

\[t = \frac{\theta}{360^\circ} \times T\]

For a 4-second sweep (\(T = 4\text{s}\)):

  • A target at \(90^\circ\) (East) triggers at: \((90 / 360) \times 4 = 1.0\text{s}\)
  • A target at \(270^\circ\) (West) triggers at: \((270 / 360) \times 4 = 3.0\text{s}\)

In SMIL, this synchronization is defined via the begin attribute relative to the sweep's cycle:

<!-- Target Blip at 90 Degrees -->
<circle cx="300" cy="200" r="4" fill="#00ff66" opacity="0">
  <animate 
    attributeName="opacity" 
    values="0; 1; 0.6; 0" 
    keyTimes="0; 0.05; 0.3; 1" 
    dur="4s" 
    begin="radarSweep.begin + 1s" 
    repeatCount="indefinite" />
</circle>

4. Simulating Phosphor Decay (The Fade Trail)

Authentic analog radars use cathode-ray tubes coated with phosphors that glow intensely when excited by the electron beam, then gradually decay.

SMIL reproduces this effect using multi-stage interpolation:

  1. Flash (opacity="1"): Reached immediately when the sweep intersects the object (keyTimes="0.05").
  2. Persistence (opacity="0.6"): A slower drop representing the primary persistence period (keyTimes="0.3").
  3. Extinction (opacity="0"): Complete fade-out before the next pass of the sweep beam (keyTimes="1").

5. Architectural Benefits of SMIL for Radar Interfaces

  • Hardware Acceleration: SMIL animations run on the browser's compositor thread, minimizing CPU frame drops associated with JavaScript requestAnimationFrame loops.
  • Data Encapsulation: Dynamic target updates can be injected into the DOM as pure SVG/XML markup. Once inserted, timing is governed independently by the SMIL animation clock.
  • Resolution Independence: Vector-based rendering ensures crisp display lines, range markings, and data labels regardless of display scaling or DPI.
