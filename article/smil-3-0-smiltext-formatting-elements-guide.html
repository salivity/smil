SMIL 3.0 smilText Formatting Elements Guide

This guide provides an overview of the structural, styling, and temporal formatting elements supported inside the <smilText> container in Synchronized Multimedia Integration Language (SMIL) 3.0. The SMIL 3.0 SMILText module allows authors to embed structured, timed text directly into multimedia presentations. Within this element, authors can use a defined set of markup tags—specifically <br/>, <clear/>, <p>, <div>, <span>, and <tev>—to structure flow, break lines, reset the display area, apply inline styles, and synchronize text with external media events.

Core Formatting Elements

The <smilText> element supports a targeted set of child elements to manage layout, formatting, and temporal progression:

  • <br/> (Line Break)
    Forces an immediate line break within the current text flow without ending the current block or paragraph context. It operates similarly to the HTML <br> element.

  • <clear/> (Clear Element)
    Erases all previously displayed text in the rendering region. When used inside timed or streaming text presentations, <clear/> resets the visual buffer before subsequent content is rendered. This is commonly used in captions, subtitles, and teleprompter-style displays to wipe the screen clean before the next set of captions appears.

  • <p> (Paragraph)
    Defines a paragraph of text. It creates a structural block boundary with default spacing before and after the text block, separating distinct thoughts or sections within the <smilText> container.

  • <div> (Division)
    Groups blocks of text or multiple paragraphs together. It allows author-defined presentation attributes (such as text alignment or font attributes) to be inherited by all enclosed child elements.

  • <span> (Inline Span)
    Applies styling to a specific run of text without triggering a line break or creating a block context. It is typically paired with presentation attributes like textColor, textBackgroundColor, fontWeight, or fontStyle.

  • <tev> (Timed Event)
    An empty milestone element used to define inline synchronization points within a continuous stream of text. Authors use the begin attribute on <tev/> tags to trigger timing actions or animate text display progressively (such as karaoke effects or word-by-word reveals).

Supporting Formatting Attributes

These formatting tags can be customized using presentation attributes defined in the SMIL 3.0 Text Styling modules, including:

  • textAlign: Controls alignment (left, right, center, justify).
  • textColor: Sets the foreground font color.
  • textBackgroundColor: Sets the background fill color behind the text.
  • fontFamily, fontSize, fontWeight, fontStyle: Control typographic properties.
  • textMode: Defined on <smilText> to dictate how text updates over time (replace, append, or scroll).

Example Implementation

<smilText textMode="append" textColor="white" textAlign="center">
  <p>
    Welcome to the presentation.<br/>
    Please standby for live captions.
  </p>
  
  <!-- Clear the screen after 5 seconds for new content -->
  <clear begin="5s"/>
  
  <p begin="5s">
    <span fontWeight="bold" textColor="yellow">Speaker:</span> 
    Let us begin the discussion.
  </p>
</smilText>
