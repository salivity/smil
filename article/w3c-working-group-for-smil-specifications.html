W3C Working Group for SMIL Specifications

The Synchronized Multimedia Integration Language (SMIL) is an XML-based standard designed for authoring interactive multimedia presentations. This article explains which World Wide Web Consortium (W3C) working group was responsible for SMIL, the current maintenance and archival status of the specifications, and which modern groups oversee related multimedia technologies.

The Original Working Group: SYMM

The SMIL specifications (including SMIL 1.0, SMIL 2.0, and SMIL 3.0) were developed and maintained by the Synchronized Multimedia Working Group (SYMM WG) within the W3C. This group was formed to create standards that coordinate the timing, layout, and synchronization of audio, video, text, and graphics on the web.

Current Archival Status

Currently, there is no active working group developing new versions of SMIL. The Synchronized Multimedia Working Group officially closed in April 2012 after publishing SMIL 3.0 as a W3C Recommendation.

As a result:

  • The SMIL specifications are formally archived by the W3C Team under the historical Synchronized Multimedia Activity.
  • The documents remain permanently published as stable W3C Recommendations for archival and reference purposes.
  • Any ongoing errata or legacy administrative oversight falls directly under the general stewardship of the W3C rather than a chartered working group.

Related Active Groups

While SMIL itself is archived, its legacy and underlying concepts persist in other active W3C groups:

  • The Timed Text Working Group (TTWG): Maintains standards like TTML (Timed Text Markup Language), which borrowed timing models and concepts from SMIL.
  • The CSS Working Group and SVG Working Group: Modern web animations and synchronized media previously influenced by SMIL animation modules are now handled via CSS Animations, CSS Transitions, and Web Animations API specifications.
